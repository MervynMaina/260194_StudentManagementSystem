## Overview

The BrightPath Student Portal is a single-page React application designed for BrightPath College to transition student academic records from manual files into a centralized web interface. Staff members can navigate student directories, view individual profiles, and access system details using a responsive, modern layout.

---

## Getting Started & Installation

Follow these steps to run the application locally on your machine.

### Prerequisites
- **Node.js**: `v18.0.0` or higher
- **npm**: Package manager included with Node.js

### 1. Installation
Clone the repository, navigate to the project directory, and install dependencies:
```bash
git clone [https://github.com/MervynMaina/260194_StudentManagementSystem.git](https://github.com/MervynMaina/260194_StudentManagementSystem.git)
cd 260194_StudentManagementSystem
npm install
npx json-server --watch db.json --port 5000
npm run dev
